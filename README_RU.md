# СНЕГ — сайт по кондиционированию и вентиляции

Готовый проект включает адаптивную главную, интерактивный каталог 44 серий, поиск, избранное, сравнение, VRV/VRF-раздел, калькулятор и пакет SEO/data/QA-артефактов.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет терминал. Для финальной сборки используйте:

```bash
npm run build
```

## Где лежат данные

- `app/catalog-data.ts` — проверенная по мастер-промту карта брендов и серий;
- `deliverables/sitemap-master.csv` — ровно 1000 запланированных маршрутов;
- `deliverables/products-master.json` — нормализованный каталог без выдуманных характеристик;
- `deliverables/docs/` — схема данных, дизайн-система, отчёты и инструкция владельцу.

## Важно перед публикацией

Контакты, реквизиты, цены, наличие, гарантии, отзывы, технические характеристики и товарные изображения намеренно не выдуманы. Подключите подтверждённые источники и снимайте `noindex` только после проверки страниц.
