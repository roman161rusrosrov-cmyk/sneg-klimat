# СНЕГ

Сайт компании по подбору, поставке, монтажу и обслуживанию систем кондиционирования и вентиляции.

## Разделы

- каталог из 44 серий Chigo, Haier, JAX, Rovex и Vickers;
- отдельные страницы брендов и каждой серии;
- решения по типам объектов;
- инженерный раздел VRV/VRF;
- услуги, база знаний и предварительный калькулятор мощности.

## Локальный запуск

Требуется Node.js 22 или новее.

```bash
npm ci
npm run dev
```

Проверка и статическая сборка:

```bash
npm run lint
npm run build:pages
```

Телефон компании задаётся в `app/business-config.ts` и автоматически используется в шапке, подвале и товарных карточках.
