# SEO-отчёт

- `sitemap-master.csv`: ровно 1000 запланированных маршрутов;
- у каждой строки есть intent, entity, source, owner, status, indexability и canonical;
- на текущем этапе все маршруты `noindex`, потому что полная проверка источников и бизнес-данных не завершена;
- цветовые варианты входят в каноническую структуру только там, где прямо перечислены в карте;
- сравнения построены между существующими сериями, но остаются draft до появления сопоставимых полей;
- кейсы остаются draft и требуют реального объекта и согласия;
- фильтры не создают индексируемые комбинации автоматически.
