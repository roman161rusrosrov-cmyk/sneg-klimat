# Производительность

Сборка не использует тяжёлое hero-видео, внешние шрифты, сторонние виджеты или аналитические скрипты. Иллюстрация hero выполнена CSS, социальная карточка загружается только как metadata-asset. Длинный каталог ограничивает начальную выдачу 12 карточками.

После добавления товарных медиа: создавать AVIF/WebP, явные размеры, responsive srcset и lazy loading вне LCP. Фактические Lighthouse/Core Web Vitals фиксируются после подключения реального домена и изображений.
