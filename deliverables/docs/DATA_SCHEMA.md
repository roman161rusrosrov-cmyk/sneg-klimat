# Схема данных

Главная сущность каталога — серия, связанная с брендом и проверенными обозначениями моделей. Техническое поле публикуется только вместе с источником.

## Обязательные поля модели

`brand`, `series`, `model`, `sku`, `product_type`, `media`, `documents`, `field_sources`, `verification_status`.

## Правило неизвестных значений

`null`, пустая строка и `unknown` не выводятся в пользовательском интерфейсе. Конфликт создаёт запись `DATA_CONFLICT`; спорное поле остаётся скрытым. Функции серии не наследуются конкретной моделью без прямого источника.

## Статусы

- `draft` — исходные данные неполны;
- `review` — шаблон и текст проверены, но публикация/индексация ещё не разрешены;
- `published` — все обязательные поля и права подтверждены.
